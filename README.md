# Box for Root

`Box for Root` — это модуль прозрачного прокси-инструментария, предназначенный для root-окружений Android (Magisk / KernelSU / APatch).

Проект в значительной степени вдохновлён следующими репозиториями и продолжает развиваться на их основе:
- [CHIZI-0618/box4magisk](https://github.com/CHIZI-0618/box4magisk)
- [taamarin/box_for_magisk](https://github.com/taamarin/box_for_magisk)

## Обзор проекта

Данный репозиторий в основном предоставляет:
- Единое управление работой основных прокси-сервисов (mihomo / sing-box / xray / v2fly / hysteria)
- Настройку правил прозрачного прокси в многосетевом режиме (TProxy / Redirect / Tun / Mixed / Enhance)
- Унифицированные скрипты для обслуживания подписок, ресурсов Geo, основных бинарных файлов и веб-интерфейса (WebUI)
- Модульную структуру каталогов и управление жизненным циклом сервисов, адаптированные к экосистеме Android Root

## Основной каталог

Рабочий каталог модуля: `/data/adb/box/`

```text
/data/adb/box/
├── bin/                # Бинарные файлы ядра прокси и утилит
├── mihomo/             # Каталог конфигурации mihomo
├── sing-box/           # Каталог конфигурации sing-box
├── xray/               # Каталог конфигурации xray
├── v2fly/              # Каталог конфигурации v2fly
├── hysteria/           # Каталог конфигурации hysteria
├── scripts/            # Основные скрипты
│   ├── box.service     # Управление жизненным циклом сервиса
│   ├── box.iptables    # Управление правилами прозрачного прокси
│   └── box.tool        # Набор инструментов для обновления и обслуживания
├── run/                # Состояние и журналы времени выполнения
└── settings.ini        # Глобальный файл конфигурации
```

## Основные скрипты

- `box.service`: управление запуском, остановкой, перезапуском, состоянием и запланированными задачами
- `box.iptables`: включение, перестройка и очистка правил прозрачного прокси
- `box.tool`: обновление подписок, обновление Geo, обновление ядра, проверка конфигурации, обслуживание WebUI
